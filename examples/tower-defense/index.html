页面模块没能加载

本页已按规范拆成 ./js/*.js（ES module）。

  1. 确认文件存在：examples/tower-defense/js/main.js、examples/tower-defense/css/ui.css
  2. 在站点根目录执行 node server.js（默认监听 0.0.0.0:39977）
  3. 用 HTTP 打开：http://localhost:39977/examples/tower-defense/（手机同 Wi-Fi 用终端打印的局域网地址）

ES module 在 file:// 下受 CORS 限制，双击直开必然失败——这不是页面的 bug。
