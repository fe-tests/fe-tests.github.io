# 🏰 塔防要塞

> Canvas 塔防：12 关 + 无尽、10 塔 ×3 级、17 种敌人（含 3 BOSS）、3 主动技能，
> 竖屏拇指热区（指尖上方 36px 落点）与双指捏合缩放地图。

| 字段 | 值 |
| --- | --- |
| 分类 | 游戏（`game`） |
| 状态 | `stable`（改状态只改 `registry.json`） |
| 标签 | `#game` `#canvas` `#tower-defense` `#塔防` `#关卡` `#移动端` `#触控` |
| 入口 | `examples/tower-defense/index.html` |
| 注册项 | `registry.json` 中 `url = "examples/tower-defense/index.html"` |
| 规模 | 12 关 + 无尽 · 10 塔 ×3 级 · 17 敌人（14 基础 + 3 BOSS）· 3 技能 · 5 种伤害类型 · 5 档目标优先级 |

## 打开方式

```bash
node server.js                    # 站点根目录执行，监听 0.0.0.0:39977
# 浏览器打开 http://localhost:39977/examples/tower-defense/
```

页面代码是 `type="module"`，**必须走 HTTP**（ES module 在 `file://` 下受 CORS 限制）。
用 `file://` 直开时，页面自带的引导守卫会在 1.2 秒内弹出提示与解决步骤，不会白屏。

## 玩法 / 用法

**一局流程**：主菜单 → 选关（或「无尽模式」）→ 布防 → 波次推进 → 结算（1~3 星）→ 下一关 / 重打。
1 星即解锁下一关；星级阈值由关卡波次表自动推导，不用手填。

**三步建造**（移动端为主设计）：

1. 点底部**塔卡**选中塔，射程圈先显示出来；
2. 点格子落位，或**按住拖到**满意位置松手（触屏落点自动抬到指尖上方 36px，手指不挡视线）；
3. 底部 **🔁 连放**开启时放完不退出，可一路点着建；**长按**约 0.4 秒 = 直接在点中的格子快速建。

**管理塔**：点一座塔 → 底部抽屉给出升级 / 目标优先级（最先 · 最后 · 最强 · 最弱 · 最近）/ 出售
（返还投入金币的 70%，出售需再点一次确认）。

**看地图**：双指捏合缩放（`fit .. 2.6×`）、双指拖动平移、单指拖动也平移；左下 **🧭** 一键看全图、**＋/－** 手动缩放；
放大后屏幕外的出怪口与基地会显示方向箭头。

**主动技能**：右侧 ☄️ 流星雨（点选落点，真实伤害）、🧊 冰封（全场冻结）、💰 富矿（金币 + 赏金加成）；
按钮带冷却环，就绪时闪一下。

**波次与经济**：底部 **🌊 开波**提前放怪，奖励 = 剩余等待秒 × 1.6；每波清空有过关奖励；击杀掉金币。
基地被漏满即失败，通关按表现评星。

**键鼠（桌面）**：`1-9` 选塔、点击放置、`U` 升级、`X` 出售、`空格` 开波、`P` 暂停、`Esc` 取消/返回、
`J/K/L` 技能（流星 / 冰封 / 富矿，W 是平移所以技能让给 JKL）、方向键 / WASD 平移、`F` 看全图、`+/-` 缩放、`?` 帮助。

**存档**：进度写本机浏览器 `localStorage`（键 `tower-defense.save.v1`），只存关卡星数 / 解锁 / 无尽最佳 / 设置；
「关卡选择 → 清空存档」需连点两次确认。隐私模式或禁用存储时自动退化为内存档，不报错。

**调试**：URL 加 `?fps=1` 显示帧率与粒子数；控制台可用 `window.TD`（见下）。

## 自动化接口

页面暴露 `window.TD`，供脚本化验证与调试：

```js
TD.version          // '1.0.0'
TD.startLevel(3)    // 直接进第 3 关；TD.startEndless() 进无尽
TD.game             // Game 实例（st / towers / setSpeed / setPaused / stepOnce …）
TD.simulate(1)      // 纯引擎模拟第 1 关（不经渲染），返回结算摘要
TD.selfTest()       // 页内自检：装配 → 引擎 → 渲染 → HUD 文本链路
TD.save()           // 当前存档对象
```

关键设计锚点：

- `config.js / engine.js / levels.js / towers.js / enemies.js` 是纯逻辑，由 `/* ENGINE-START */ … /* ENGINE-END */`
  标出，可被 Node 直接 import 校验（不碰 DOM）。
- **地形每关烘焙一次**进离屏画布，主循环只 `drawImage` 一次，其余是动态层；实体按 `viewRect()` 剔除。
- 逻辑固定步长 `1/60`，每帧最多 8 步（倍速时上限 ×3），掉帧积压丢弃，快进不会让弹道与判定失真。
- 所有全局倍率在 `BAL` 一个对象里（塔伤/射速/造价、敌人血量与成长、赏金、起始金币…），数据表保持原值。
- 星级阈值由波次表推导（约理论血量总量的 55% / 76% / 92%），**评分模型与金币缩放解耦**，
  调金币经济不会让阈值失效。

验证方式（站点根目录）：

```bash
node examples/tower-defense/tools/smoke.mjs      # 数据 / 平衡 / 模块图 / DOM 契约
node examples/tower-defense/tools/headless.mjs   # 装配 → 引擎 → 渲染 → 事件 → 存档 全链路
```

`smoke` 用自动玩家跑完 12 关与无尽，作为「可通关」证明，并校验数据表、模块图与 DOM/CSS/hooks 契约；
`headless` 用替身 DOM + 代理 2D 上下文跑真实 `Game.frame` 与 `main.js` 的入口装配，
连打一关拿到 ★3、`TD.selfTest()` 全绿才算通过。两个脚本合计 **92 项断言**，退出码非 0 即视为回归。

## 依赖

- **无外部依赖**：原生 HTML/CSS/JS，零构建、零 npm 包、零网络请求；贴图、图标（emoji）、音效全部程序化生成。
- 运行时特性：Canvas 2D / Pointer Events / Web Audio / localStorage / `navigator.vibrate` / `100dvh` 与安全区变量。
- 页面目录内的 `package.json`（`{"type":"module"}`）只用于消除 Node 的 typeless-package 警告，不参与站点构建。

## 已知问题与限制

- **无浏览器自动化**：像素级呈现、真机触控手感、音频解锁时序需要人在页面里点一遍；
  Node 侧已覆盖逻辑、装配与契约（见上两个脚本）。
- 存档按浏览器隔离，清浏览器数据会掉进度；刻意**不做**云存档、科技树、离线收益。
- 依赖 Pointer Events（现代浏览器均支持），不做 `touch` 事件降级。
- emoji 图标依赖系统字体；缺 emoji 字体的环境会显示方框（未内置图标字体，换取零依赖与体积）。
- 无尽模式波次数学在 40+ 波后敌人数量与血量增长很快，追求「跑分」而非平衡通关。
- 低端机上「流畅」档（粒子上限 120、DPR ×0.8）才是默认帧率保障；「华丽」档适合桌面独显环境。
- 单关最长了局时长约 4~5 分钟（×1）；倍速 ×3 可压到 90 秒内。

## 改这份页面时

- 改标题/简介/分类/标签/状态/置顶：只改 `registry.json` 对应条目（`url` 是去重键）。
- 返回门户写 `href="/"`；顶级共享资源写 `../../assets/...`；页面自身文件写 `./js/...`、`./css/...`。
- 平衡只改 `js/config.js` 的 `BAL`；关卡只改 `js/levels.js` 的波次表（星级自动推导，别手填 `stars`）。
- 改完跑 `node examples/tower-defense/tools/smoke.mjs` 与 `tools/headless.mjs`，两个都必须退出码 0。
