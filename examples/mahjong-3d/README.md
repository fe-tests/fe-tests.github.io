## 打开方式

站点根目录启动零依赖静态服务器，再用浏览器打开本页目录：

```bash
node server.js                                      # 监听 0.0.0.0:39977（含局域网地址）
# 浏览器打开 http://localhost:39977/examples/mahjong-3d/
```

本页以桌面键鼠操作为主，移动端表现见 [docs/design.md](docs/design.md) 的交互小节。
