## 玩法 / 用法

全屏动画，无通关概念，纯展示 + 可调参。进入即自动播放（带 1.7 秒「算力生成」入场：镜头从 6.4 → 4.15 拉近、球体从 0.55 → 1.0 放大）。

| 操作 | 桌面 | 移动端 | 效果 |
| --- | --- | --- | --- |
| 环绕视角 | 拖拽（pointer 事件） | 单指滑动 | 偏航 / 俯仰，带惯性；松手 2.2 秒后自动回到自动环绕 |
| 缩放 | 滚轮 | 双指（走 wheel 兼容） | 视距 3.0 ↔ 6.8 |
| 视差 | 鼠标悬停移动 | — | 镜头微位移 + 轻微色散，强化立体感 |
| 暂停 / 继续 | `空格` | 面板滑杆把「粒子流动速度」拉到 0 | 冻结 `state.t`，`requestAnimationFrame` 不退出 |
| 辉光开关 | `B` | — | 关掉 bloom 合成，直接看原图 |
| 帧率显示 | `F` | — | 右上角显示 fps 与渲染分辨率 |
| 字幕 | `H` | — | 显示 / 隐藏「AI 模型疯狂计算中」字幕 |
| 参数面板 | 右下角 `算力参数` | 同 | 自转速度 / 流动速度 / 粒子数量 / 粒子尺寸 / 辉光强度 / 镜头视差 |

面板 6 条滑杆即时生效：`球体自转速度` 0～0.6 rad/s（默认 0.09，恒定匀速），`环境粒子数量` 0～2200（默认 1400，改的是 `drawArrays` 的 count，不重建缓冲）。

## 实现概览

页面目录实际结构：

| 文件 | 职责 |
| --- | --- |
| `index.html` | 骨架、样式、着色器、几何、渲染循环、UI（全部在内，`ENGINE-START/END` 锚点包住可抽离的纯逻辑） |

场景由内向外 7 层，全部走加色混合（`gl.blendFunc(gl.ONE, gl.ONE)`）+ 关闭深度写入，因此绘制顺序无关、天然发光叠加：

| 层 | 几何 | 运动来源 |
| --- | --- | --- |
| 中央算力核心 | 3 个面向相机的 billboard sprite（核心 + 两层大气辉光） | `uTime` 正弦脉冲 + 高频闪烁 |
| 网络球体 | 二十面体细分 2 级 → 162 顶点点云 + 480 棱边 `LINES` + 棱边中点「算力节点」 | JS 侧 `uModel = rotY(t × 速度) · rotX(-0.18) · scale`，**匀速** |
| 内核球壳 | 斐波那契球面 110 点 | 反向 0.55 倍速自转，制造前后层次 |
| 赤道能量环 / HUD 弧环 | 6 条平面环 `LINE_LOOP` + 5 条弧段 `LINE_STRIP` | 着色器 `uDash`/`uDashSpd` 让虚线沿环流动，环各自转速 |
| 环境尘埃 | 体积点云 ≤2200 点 | 顶点着色器绕 Y **差分自转**（`speed = 1.1 / r`，越远越慢）+ 上下浮动 |
| 远端穹顶 + 彗星 | 17×96 双层点阵 + 6 条 26 段拖尾线 | 点阵慢自转；彗星在球面大圆上推进，尾迹 `tailT` 衰减 |
| 3D 数据流 | 30 列 × 13 段 `LINES` | 顶点着色器算 `head = fract(t·speed + seed)` 沿 Y 下落 |

后处理链（4 个 FBO：`fboScene` 全分辨率 + `fboA`/`fboB` 半分辨率）：

```
场景 FBO ─▶ 亮通道提取(阈值 0.40) ─▶ 横向高斯 ─▶ 纵向高斯 ─▶ 合成(叠加 + 暗角 + 色散 + 噪点 + 扫描线)
```

关键点：

- **立体动感**由三件事叠加：相机自动环绕 + 鼠标视差 + 尘埃差分自转（近快远慢），球体自转只是其中一条。粒子尺寸按 `1 / clip.w` 透视衰减，透明度按 `smoothstep(uFogN, uFogF, d)` 距离衰减，远端粒子更小更暗 → 体积感。
- 每帧 27 次 `drawArrays`：5 次点（球顶点 / 棱边节点 / 球壳 / 尘埃 / 穹顶）、14 次线（球棱边 1 + 能量环 6 + HUD 弧 5 + 彗星 + 数据流）、3 次 sprite、5 次全屏与后处理；零纹理贴图，全部程序化几何。
- 时间基准：`state.t += dt × 自转/流动速度`，暂停只冻结 `state.t`；`dt` 上限 0.05 秒，切标签回来不会被大 `dt` 跳帧。
- 渲染分辨率：`min(devicePixelRatio, 2)`，宽度上限 2400（移动端 1500）。

代码锚点：`/* ENGINE-START */ … /* ENGINE-END */` 之间是纯逻辑（矩阵工具、几何生成、着色器字符串、状态机），无 DOM 依赖，可整段搬进 Node 用 mock GL 跑烟雾测试。

## 依赖

- **无外部依赖**：原生 HTML/CSS/JS + WebGL 1.0，零构建、零 npm 包、零图片资源。
- 运行时特性：WebGL 1.0、`pointer` 事件、CSS `backdrop-filter`、CSS keyframe 动画（数字雨与字幕省略号）。
- 页面目录自包含：不引用 `assets/vendor/` 与其它页面目录。

## 已知问题与限制

- **线宽固定 1 px**：WebGL 1.0 里 `gl.lineWidth` 普遍被驱动钳制到 1，参考图里的「粗发光环」靠 bloom 叠加得到；关掉辉光（按 `B`）会明显变细。需要真·粗环要改成 ribbon 三角形带（已评估，暂不做）。
- **软件渲染设备**（无 GPU / 远程桌面）：SwiftShader 下 1400 粒子 + bloom 会掉到 20 fps 以下，把「环境粒子数量」和「辉光强度」调低即可。
- **无 WebGL 时**：只显示提示面板（说明需要 WebGL 1.0 context 与硬件加速），不做 2D 简版——本页是纯 GPU 特效，2D 版会失去全部意义。
- 移动端无鼠标视差（触摸只有拖拽）；未做双指缩放手势（`wheel` 之外无 `gesturestart` 处理）。
- 无音效、无 `prefers-reduced-motion` 降级（动画本身是常驻型，停了就没有内容可看）。
- 无持久化：参数面板刷新即重置（见 [docs/design.md](docs/design.md) 第 6 节）。

## 改这份页面时

- 改标题/简介/分类/标签/状态/置顶：只改 `registry.json` 对应条目，首页刷新即生效（`url` 是去重键，勿与其它条目重复）。
- 改视觉效果优先动 `CFG` 常量与 `frame()` 里的每层 `setPts/setLines` 参数（`sizeBase`、`alpha`、`fogN/fogF`、颜色 `col.*`），别改几何函数。
- 返回门户写 `href="/"`；本页无外部资源引用。
- 超过软上限（单文件 ~1200 行）就拆 `js/` + `css/`：建议边界 `js/geometry.js`（几何与矩阵）、`js/shaders.js`（GLSL 字符串）、`js/render.js`（FBO 与 draw 调用）、`js/ui.js`（面板与键位），并在 devlog 记一笔拆分原因。
