🧩 3D 魔方 · 操作说明

拖拽转面：在魔方贴纸上按住并拖动 → 自动判定转动哪一层（桌面与触屏一致）； 在空白处拖动 → 旋转视角；滚轮 / 双指捏合缩放；双击复位视角。

逐步复原：打乱后按 ▶ 逐步复原，程序逆序回放「打乱 + 你的转动」并做序列压缩， 配合 0.25x~4x / ∞ 变速与进度条快照跳转，可任意时刻查看中间状态。

键作用
u d l r f b对应面顺时针 90°；Shift+键 = 逆时针；先按面键再按 2 = 180°
m e s中层切片转动（Shift = 反向）
Ctrl+u d l r f b宽层转动（u d l r f b，两层一起转）
x y z整体立方体旋转（Shift+x/y = 反向；Shift+Z 已留给复原）
Space播放 / 暂停复原回放
← →时间轴上一步 / 下一步（快照瞬时跳转）
Q / Shift+Z / T打乱 / 逐步复原 / 重置
V / 2 / Esc复位视角 / 切换 2D 视图 / 关闭弹窗
